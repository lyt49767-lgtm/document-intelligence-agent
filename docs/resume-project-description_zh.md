# 企业文档智能检索 Agent

## 项目背景

企业文档检索中，纯语义检索难以稳定满足生命周期阶段、主题、日期等强约束筛选；同时 PDF 的文本、表格和版面信息不便直接被下游系统使用。项目构建可部署的文档智能 Agent，将结构化检索与 PDF 解析封装为可编排工具，并返回可追溯来源。

## 项目职责

- 使用 FastAPI 设计文档检索、PDF 解析和 `/api/ask` Agent 编排接口。
- 设计规则化路由：识别问题中的阶段/主题检索条件，按需调用目录检索、PDF 解析或混合流程。
- 基于 PyMuPDF 提取页级文本块、原生表格和坐标信息，并在内存中处理上传文件。
- 设计工具调用记录与文档/页码引用，确保回答过程可解释、结果可追溯。
- 使用 Docker、Render Blueprint、GitHub Actions、Ruff、Mypy 与 Pytest 建立可部署质量链路。

## 主要产出

- 支持结构化元数据检索、文本型 PDF 结构提取和自然语言入口的工具编排。
- `/api/ask` 输出路由类型、调用工具、检索结果与页级证据；无需外部模型 Key 即可运行。
- 提供 Docker 部署、健康检查、CI 自动化验证；包含 9 个接口与业务测试用例。
